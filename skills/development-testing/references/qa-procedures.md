# Procedural and exploratory QA

## Manual tests

Record the test objective, build, environment, and initial conditions.
Use an authorized test environment.
Write one action in each numbered step.
Give the expected result after each applicable step.
Give the logs, screenshots, or other test results to record for each test.
Include instructions for test cleanup.

## Exploratory tests

Before the session, set a time limit.
Select a user task and a failure risk.
For each defect, record the steps, expected and actual results, environment, build, and available logs or screenshots.
