# Write in Simplified Technical English

Use ASD-STE100 Issue 9 for new or changed English technical text when the project and user rules let you. Examples include procedures, technical documentation, and pull request descriptions. Keep the specified language, templates, names, commands, and quoted text.

1. Use the active voice.
2. Use the imperative form for instructions.
3. Put a condition before its instruction.
4. Use one instruction per sentence.
5. Use a maximum of 20 words in procedural sentences.
6. Use a maximum of 25 words in descriptive sentences.
7. Use the approved words with their approved meanings and parts of speech.
8. Use necessary technical nouns and verbs from the subject field.
9. Use the same term for the same item.

Before delivery, read the changed text again. If you are not sure about a word, use the dictionary in the [ASD-STE100 standard](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf). If you do not have the standard, give the user the limit of the language check.
